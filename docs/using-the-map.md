# Using the map

What the map controls do. Sources and limits of tree height are in [Data notes](data.md).

## Layer groups

The drawer has two groups, **Threats** and **Interest**. All, Built, Treeloss, Fire, Bare, Mines, Crops, Rivers and Dams are under Threats. Tree height is under Interest.

Each layer still has its own visibility button and opacity control. Coming soon layers stay disabled. The basemap switch and label control stay on the map. They are not part of either group.

## Tree height and the timeline

Tree height is a 2020 layer. The button matches the other layer buttons. The year is in the About text, and it also appears when you hover the button. Changing the timeline year does not change the tiles, including when the year is before 2020. Other layers still follow their own years: if a layer has no data for the selected year, the map uses its latest earlier year, and if every published year is later, that layer is not requested.

## What the tree height colours mean

Pale green is about 3 m, mid green is about 15 m, and dark green is about 30 m or taller. The colours are already in the tiles. The legend, source, observation year and limits are in the layer’s About text, opened from the information button.
