# Parcel: Transport

A [Threat Layers](threat-layers.md) parcel. Railways are added to the Roads layer, which may be renamed Transport, and drawn distinct from roads.

*Started 27 November 2026 as notes. Not defined yet. It is small, so it can go in any gap between the other Threat Layers parcels.*

## Notes

- **Source.** Overture transportation segments with subtype `rail`, from the roads release `2026-10-21.0`.
- **Sprout.** Its own `railways` sprout, so the sandbox weights rail apart from roads.
- **Tiles.** Raster, like Roads, in its own archive or as a class in a new roads version.
